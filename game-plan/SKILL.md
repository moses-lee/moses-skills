# Game Plan

Plan resolutions for the supplied issues. Fold in mechanical fixes:
corrections with an established outcome and no meaningful behavior,
design, or scope decision. Small doesn’t mean mechanical. Apply fixes
only when implementation is in scope.

For everything else, investigate first, then ask one item at a time.
Use watercooler-talk to explain the behavior, problem, and decision
with enough technical context.

Ask a multiple-choice question with viable options, trade-offs, and
your recommendation; allow custom answers. Use the interactive question
tool when available. Wait for each answer before the next question,
and honor prior decisions.

Consolidate the resolutions into a plan.
